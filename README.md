# Soop AI — гайд

Лендинг о покупке подписки Soop AI в боте FastBuy и размещении лота на FunPay. Внутри пошаговый гайд, калькулятор и галерея из 13 скриншотов.

## Как открыть

Открой `index.html` в браузере. Для работы над сайтом в Codex добавь папку `soop-ai-guide` как проект. Установка зависимостей и сборка не нужны.

## Файлы

- `index.html` — тексты, ссылки и список скриншотов галереи.
- `styles.css` — оформление и анимации.
- `guide.js` — калькулятор и управление галереей.
- `assets/` — иллюстрация и скриншоты для сайта.
